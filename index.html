Capstone Artifact

Original Artifact: Grazioso Salvare Rescue Animal Dashboard

The Grazioso Salvare Rescue Animal Dashboard was originally created for CS 340: Client/Server Development. The application uses Python, Dash, MongoDB, PyMongo, Pandas, Plotly, and Dash Leaflet.

The dashboard allows a user to view animal shelter records, filter animals based on different rescue categories, review breed information, and display the location of a selected animal on an interactive map.

Enhancement One: Software Design and Engineering

For the software design and engineering enhancement, I plan to reorganize and refactor the application into a cleaner and more modular structure. I will separate major parts of the application based on their responsibilities and improve error handling, configuration management, documentation, and testing.

I also plan to improve security by removing database credentials from the source code and loading them through a safer configuration method.

Enhanced artifact and narrative will be added during Module Three.

Enhancement Two: Algorithms and Data Structures

For the algorithms and data structures enhancement, I plan to create a rescue-candidate scoring system. Instead of only filtering animals, the application will evaluate candidate records and assign a suitability score based on characteristics connected to a selected rescue type.

The candidates will then be ranked from strongest to weakest match. This enhancement will demonstrate algorithm design, sorting, filtering, data structures, and evaluation of design trade-offs.

Enhanced artifact and narrative will be added during Module Four.

Enhancement Three: Databases

For the database enhancement, I plan to expand the MongoDB portion of the project by improving queries and making greater use of database functionality. This may include MongoDB aggregation pipelines, indexing, improved CRUD operations, and safer database interaction.

I will also review how the application handles database credentials and user input so that the final project demonstrates a stronger security mindset.

Enhanced artifact and narrative will be added during Module Five.
