Capstone Artifact

Original Artifact: Grazioso Salvare Rescue Animal Dashboard

The Grazioso Salvare Rescue Animal Dashboard was originally created for CS 340: Client/Server Development. The application uses Python, Dash, MongoDB, PyMongo, Pandas, Plotly, and Dash Leaflet.

The dashboard allows a user to view animal shelter records, filter animals based on different rescue categories, review breed information, and display the location of a selected animal on an interactive map.

Enhancement One: Software Design and Engineering

For my software design and engineering enhancement, I refactored the Grazioso Salvare Rescue Animal Dashboard to improve its organization, maintainability, reliability, and security.

Software Architecture Improvements

The original application contained several responsibilities within a single Jupyter notebook. I reorganized the application into separate Python modules, each responsible for a specific part of the system.

  • animal_shelter.py: Handles MongoDB database operations and error handling.
  • rescue_filters.py: Defines the rescue-category filtering rules.
  • visualization.py: Creates the breed chart and geographic map.
  • Dashboard notebook: Manages the user interface and connects the components.

Security and Reliability

I improved configuration management by separating database connection settings from the application source code. Environment variables allow configuration values to be managed without hardcoding them into the program.

I also improved input validation, exception handling, and automated testing. These changes make the application easier to maintain and help identify problems before they affect the dashboard.

Skills Demonstrated

This enhancement demonstrates modular software design, separation of concerns, database integration, testing, configuration management, and secure development practices. It also provided the foundation for the later algorithm and database enhancements.

Course Outcomes Demonstrated

This enhancement supports the course outcomes involving software engineering practices, implementing computing solutions that deliver value, and developing a security mindset that anticipates vulnerabilities and protects application resources.

Enhancement Two: Algorithms and Data Structures

For my algorithms and data structures enhancement, I expanded the Grazioso Salvare Rescue Animal Dashboard by implementing a weighted rescue-candidate scoring and ranking system. Instead of simply filtering animal records, the enhanced application evaluates how closely each animal matches the characteristics associated with a selected rescue category.

Weighted Candidate Scoring

The scoring algorithm evaluates three characteristics:

  • Breed compatibility (50 points): Breed receives the greatest weight because it is the primary matching characteristic in the rescue profiles.
  • Preferred age range (30 points): Age receives the second-highest weight because the original rescue criteria identify preferred age ranges for different rescue assignments.
  • Sex preference (20 points): This criterion preserves the preferences defined in the original rescue profiles while assigning them the lowest weight.

These weights are project-specific design choices rather than scientifically validated measures of an animal's actual rescue ability.

Ranking and Algorithm Design

Each candidate receives a suitability score of up to 100 points. Candidates that do not match any of the preferred characteristics are excluded, while the remaining candidates are sorted from highest to lowest score.

The algorithm uses Python dictionaries, lists, filtering, and sorting to organize candidate records. It also creates copies of the records so that the original animal data is not modified during scoring.

Testing and Instructor Feedback

I verified the scoring and ranking functionality through automated testing and manual dashboard testing. The completed capstone application passed 30 automated tests across its database, filtering, scoring, and visualization components.

Following instructor feedback, I expanded the algorithm's documentation to explain why each characteristic receives its assigned weight. This makes the scoring decisions easier to understand, evaluate, and adjust.

Enhancement Three: Databases

For my database enhancement, I improved the MongoDB functionality of the Grazioso Salvare Rescue Animal Dashboard by introducing database-side aggregation, explicit index-management methods, and expanded automated tests.

MongoDB Aggregation and Visualization

I added a MongoDB aggregation pipeline that matches the relevant animal records, groups them by breed, and sorts the breed counts. The dashboard uses the resulting counts for its breed chart while keeping the chart tied to the currently filtered animal records.

Index Management and Security

I added methods for creating and inspecting indexes on fields used in rescue queries, including animal type, breed, sex, and age. Index creation is an explicit administrative action rather than an automatic dashboard startup operation. Database credentials are loaded from environment variables instead of being embedded in the source code.

Testing and Design Trade-Offs

The completed application passed 30 automated tests covering database behavior, filtering, candidate scoring, and visualization. Mocked database tests verify aggregation and index methods without modifying live records. The visualization also retains a fallback path if aggregated results are unavailable. The project demonstrates indexing functionality but does not claim measured performance improvements or deployment of indexes to a production database.

Skills and Course Outcomes Demonstrated

This enhancement demonstrates database design, MongoDB aggregation, indexing, Python database integration, automated testing, and the evaluation of where data processing should occur. It supports the course outcomes involving computing tools that deliver value, algorithmic design trade-offs, and a security mindset.
