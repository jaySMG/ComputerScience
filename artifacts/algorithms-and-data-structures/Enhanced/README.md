# Enhanced Artifact — Algorithms and Data Structures

This folder contains the enhanced Grazioso Salvare Rescue Animal Dashboard developed for CS 499.

The primary improvement is a weighted candidate-scoring algorithm that evaluates animals against rescue-specific profiles and ranks candidates by suitability.

The scoring system uses three criteria:

- Breed compatibility: 50 points
- Preferred age range: 30 points
- Original rescue profile's sex preference: 20 points

These weights are project-specific design choices, not scientifically validated predictions of rescue performance.

The enhancement also includes modular Python code, automated tests, and integration with the dashboard's rescue filtering and visualization features.
