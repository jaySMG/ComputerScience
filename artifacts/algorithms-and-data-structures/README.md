# Algorithms and Data Structures Enhancement

**Artifact:** Grazioso Salvare Rescue Animal Dashboard  
**Course:** CS 499 Computer Science Capstone

This enhancement introduces weighted rescue-candidate scoring and ranking to the original animal shelter dashboard.

Candidates are evaluated using breed compatibility (50 points), age range (30 points), and the original rescue profile's sex preference (20 points). These weights are application-specific design choices rather than validated predictions of an animal's rescue performance.

The enhancement also includes automated testing and documentation explaining the algorithm's design decisions.

The Original folder contains the original CS 340 artifact. The Enhanced folder contains the improved application and its supporting Python modules. The Narrative folder contains the written reflection on the enhancement.
